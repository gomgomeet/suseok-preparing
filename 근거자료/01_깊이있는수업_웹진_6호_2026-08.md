## 1. 지도안에 그대로 쓸 수 있는 핵심 원리

### 1-1. 질문기반 탐구수업 (미사초 수석교사 권수경, 6~11쪽)

| 원리 | 요지 | 지도안 반영 포인트 |
|---|---|---|
| 질문이 생기는 지점 | 질문은 '모를 때'보다 알던 생각과 어긋나는 사실·예상과 다른 결과·충돌하는 주장을 만날 때 생긴다. (예: 넓이가 같은데 둘레는 왜 다를까?) | 도입에 **인지적 갈등 장면**을 배치 |
| 질문을 '만든 것' ≠ 질문이 '생긴 것' | 개수·형식(열린/닫힌 질문 분류)이 목표가 되면 질문은 또 하나의 과제가 된다. | 질문 활동의 평가 기준을 개수가 아닌 **탐구로 이어졌는가**로 |
| 학생 질문 → 공동 탐구질문 | 모든 질문을 다룰 수는 없지만, 비슷한 질문을 묶고 핵심 내용과 연결해 학급의 탐구질문으로 재구성한다. | 차시 흐름에 **질문 수렴·재구성 단계** 명시 |
| 교사 질문의 역할 | 학생 질문을 강조해도 교사 질문은 사라지지 않는다. 궁금증 꺼내기 → 좁히기 → 정리 → 실제 문제 적용으로 단원 전체 흐름을 설계한다. | 단원 수준의 **질문 흐름표** |
| 탐구질문의 세 열쇠 | 사실 확인 질문(재료 쌓기) → 개념적 질문(연결·일반화) → 논쟁적 질문(근거 기반 판단). 논쟁적 질문은 처음에 문 앞으로 이끌고, 끝에 다시 돌아와 사고를 넓힌다. | 차시별 탐구질문을 **사실·개념·논쟁** 유형으로 표기 |
| 사고 수준 확인 | SOLO 분류(전구조→단일→다중→관계적→확장추상)로 학생 답의 깊이를 본다. | 성취수준 A·B·C 기술에 **관계적·확장추상 수준** 반영 |
| 맺음 | 질문 없는 탐구는 시킨 과제가 되고, 탐구 없는 질문은 활동지의 물음표로 남는다. | 지도안 설계 의도 문단에 인용 가능 |

### 1-2. 소식지 사례가 공통으로 쓰는 단원 설계 틀

**단원 설계표**: 단원명(주제) / 핵심 아이디어(교육과정 원문) / 핵심어 / 핵심 문장 / 핵심 질문 / 차시 묶음별 주요 활동 / 탐구 질문 목록

**차시 과정안**: 성취기준 / 탐구 질문 / 단계(준비 → 탐구 → 정리·실천 → 성찰) / 피드백 및 유의점 / **학습으로의 평가**(평가요소 · 성취수준 · 평가방법)

> 수석교사 지도안 작성 시 이 틀을 그대로 쓰면 '깊이있는 수업' 정책 용어와 일치합니다. 성취수준은 이 저장소의 `학년별/N학년.md` 영역 성취수준(A·B·C)을 연결하세요.

### 사례 1. 민주주의 속 미디어 홍수에서 살아남기 — 선단초 황인영 (12~17쪽)
- **설계 의도**: '허위 정보를 어떻게 구별할까'보다 먼저 '**왜** 비판적으로 봐야 하는가'를 사례 분석·토의로 스스로 발견하게 함.
- **핵심 질문**: 사람들은 왜 미디어를 비판적으로 분석해야 하는가? / 13차시(이해 1–3 → 비판적 분석 4–9 → 시민 실천 10–13)
- **공개 차시 흐름**: 허위 제보 사진을 See-Think-Wonder로 분석 → 탐구질문 "민주주의에서 미디어를 그대로 믿어도 될까?" → 모둠별 사례를 '주장–근거–더 필요한 정보'로 분석(하이러닝) → 허위 정보가 개인·사람들의 판단·민주주의에 미치는 영향 토의 → '예전 생각–지금 생각' 성찰.
- **평가**: 허위 정보가 민주주의에 미치는 영향 설명하기, 4단계(매우잘함~노력요함), 토의·토론.
- **성찰에서 얻을 점**: 학생들이 "이제 미디어를 믿지 않겠다"로 정리 → **무조건 의심이 아니라 기준에 따른 판단**으로 다음 차시에서 보완. 교사가 학생 답을 교사 언어로 다듬어 버린 점을 아쉬움으로 꼽음 → **기다림의 시간 확보**.

### 사례 2. 서로를 존중하며 포용성의 의미 정의하기 — 안양덕현초 박선연 (22~29쪽)
- **설계 의도**: 말수가 적고 위축된 학급 → '정서적 안정감 위의 탐구'. 사회정서교육(마음챙김)과 가치 탐구 결합.
- **핵심 질문**: 문학을 통해 서로의 생각을 나누는 것은 우리에게 어떤 도움이 될까? / 9차시(가치 개념 정의 → 인물 탐구·인생 그래프 → 인물 인터뷰 → 나와 인물의 가치 비교 → 가치 사전 만들기)
- **공개 차시 흐름**: 시 감상으로 가치 개념 열기 → 그림책 『아름다운 가치 사전』으로 정의 살펴보기 → **개념 탐구 모형**(예·반례·특성)으로 모둠별 '포용성' 정의 → 갤러리 워크로 정의 비교 → 내 삶의 포용성 사례 발표.
- **평가**: 가치 개념 이해 / 인물과 나의 가치 비교 / 수용하는 태도, 구술·토의.

### 사례 3. 글을 읽고 자신의 생각 표현하기 — 매교초 이하영 (30~37쪽, 2학년)
- **설계 의도**: 매체를 소비만 하던 2학년을 '소통가'로. 교과서 이야기에 '내가 별나라에 가야 하는 까닭' 설정을 더해 학생을 이야기 주인공으로.
- **핵심 질문**: 글을 읽고 글에 대한 생각을 나누면 어떤 점이 좋을까? / 15차시, 마무리는 책 소개 포스터 + **북 큐레이터 박람회**(갤러리 워크, 질문 막대, 방명록).
- **공개 차시 흐름**: 별나라 초대장으로 내용 떠올리기 → 역할 읽기 → 보내고 싶은 동물에 **이름표 붙이기** → 친구 의견 듣고 **이름표 옮겨 붙이기**(생각이 바뀐 까닭 말하기) → 편지 쓰기 → 성찰.
- **평가**: 자신의 생각과 까닭 표현 / 친구와 공유·소통, 구술.
- **저학년 지도안 포인트**: 소수 의견이 존중되도록 발문 설계, 생각을 1차 정리 → 듣기 → 수정의 단계적 흐름.

### 사례 4. 계절에 따라 별자리는 왜 달라졌을까? — 광명서초 백선영 (38~45쪽)
- **설계 의도**: '지구는 공전한다'를 정답으로 받아들이기보다, 옛 과학자의 눈으로 **가능한 설명들을 세우고 모형으로 검토**하는 과학의 본성 경험. IB 관점의 전이 개념 '규칙성(Pattern)'·'관점(Perspective)'.
- **핵심 질문**: 인간은 왜 하늘에 보이는 천체의 움직임을 이해하려 했을까? / 16차시(탐구 준비 → 규칙성 발견 → 관측자 관점과 지구의 운동 → 인간 삶과의 연결)
- **공개 차시 흐름**: 계절별 밤하늘에서 규칙 발견 → 가능한 설명(가설) 모둠 토의("다른 설명도 가능하지 않을까?") → 선택한 설명대로 모형 실험 → 결과 비교·모순 발견·모형의 한계 논의 → 실제 과학자의 탐구와 비교·성찰.
- **평가**: 다양한 설명 제안·모형 검토 / 과학적 탐구 과정 성찰, 관찰·모형 실험·탐구 성찰지·발표.

### 사례 5. 그림책 속 숨은 이야기를 찾아라 — 오마초 곽선우 (46~53쪽, 4학년)
- **설계 의도**: 16면짜리 그림책(『할머니의 용궁 여행』, 수궁가 패러디)을 **18차시 슬로 리딩**으로. 면지의 작은 메시지(해녀 수칙)까지 수업으로 확장.
- **교과 통합**: 국어(1–6) → 미술(7–10, 용궁 속 인류 예술품) → 사회(11–13, 바다 생물의 현실) → 도덕·사회(14–18, 앞뒤 면지 비교, 학생 수칙, 카드뉴스 캠페인). 국어·사회·도덕·미술 핵심 아이디어를 모두 끌어옴.
- **공개 차시 흐름**: 하드커버·면지 탐색 → 표지 속 해녀와 실제 해녀 비교(재활용 상징에서 작가 의도 추론) → 해녀 수칙의 필요성 → '수칙'의 뜻(한자어) → 운전자 수칙으로 일반화 → 우리 반 학생 수칙 정하기.
- **평가**: 수칙이 필요한 대상·상황 말하기 / 학생에게 필요한 수칙 말하기, 구술.
- **수석교사 컨설팅(오마초 김인정, 52쪽)**: 수석교사가 학교 안 '탐구공동체'를 조직해 함께 설계·실행. 토의 수업은 평소의 토의 훈련이 쌓여야 가능하다는 점을 강조.

### 사례 6. 계산식의 배열에서 규칙 찾기 — 세담초 이동준 (56~60쪽, 4학년)
- **설계 의도**: 계산식 배열에서 **변하는 부분과 변하지 않는 부분의 관계**를 스스로 발견하고 설명하게 함.
- **핵심 질문**: 일정하게 변화하는 규칙은 무엇일까? / 10차시(수 배열 → 모양 배열 → 식으로 표현 → 계산식 배열 → 등호 → 문제해결)
- **공개 차시 흐름**: 눈치 게임(다음 계산식 맞히기) → 탐구질문 "덧셈식과 뺄셈식이 늘어선 배열에는 어떤 규칙이 있을까?" → 하이러닝 공유로 모둠 규칙 탐구 → 규칙 만들어 공유 → 알게 된 점·궁금한 점 작성.
- **평가**: 규칙 찾기·설명하기, 논술형·서술형.
- **수석교사 컨설팅(청연초 정유경, 60쪽)**: 규칙 **발견 → 근거로 설명 → 새 상황에 적용** 세 단계가 이어지는지 점검. 학생마다 알아차리는 시점이 달라 **단계적 실마리**와 다양한 표현 방식(표·그림)을 열어 둠, 짝과 근거 비교.

## 4. 수석교사 지도안·면접에 쓰기 좋은 문장 재료 (요약)

- 질문은 수업의 장식이 아니라 탐구의 문을 여는 열쇠다. 학생이 열쇠를 스스로 만드는 경험이 쌓여야 낯선 문 앞에서도 멈추지 않는다.
- 활동에 참여했다는 사실만으로 탐구가 되지 않는다. 활동이 학생의 질문·사고와 연결되어 생각의 변화를 만들 때 탐구가 된다.
- 깊이있는 수업의 성찰 공통점: 교사가 학생 답을 대신 다듬는 순간 사고가 멈춘다 → **기다림**과 **학생 언어로의 정리**.
- 수석교사의 컨설팅 역할(사례 5·6): 학교 안 수업 공동체를 조직하고, 설계–실행–촬영–성찰을 함께하며, 단계적 실마리와 근거 비교 활동을 제안한다.
