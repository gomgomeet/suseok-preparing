## 1. 핵심 원리: 깊이있는 학습을 위한 수업의 지도, 통합 설계 (도영호 장학사, 6~11쪽)

| 원리 | 요지 | 지도안 반영 포인트 |
|---|---|---|
| 차시의 합 ≠ 단원의 배움 | 좋은 차시가 모여도 단원의 핵심 이해로 이어지지 않으면 배움이 깊어지지 않는다. 활동은 풍성해도 남아야 할 개념이 흐릴 수 있다. | 지도안 앞부분에 **단원 전체의 배움 지도** 제시 |
| 출발점의 전환 | '오늘 어떤 활동을 할까'가 아니라 '이 단원에서 학생이 무엇을 깊이 이해해야 하나'에서 출발 → 배움의 흐름·평가 과제·차시 질문을 거기에 맞춤 | 백워드: 기대하는 학습 결과 → 증거 → 경로 |
| 배움의 덩어리 | 활동 중심 유목화가 아니라 **개념을 연결하는 배움의 덩어리**로 단원을 조직 | 차시 묶음을 '배움①②③'으로 명명 |
| 징검다리평가와 전이 평가 | 배움 형성 지점마다 징검다리평가, 마지막엔 배운 것으로 생각·판단·해결하는 **전이 과제** | 평가 계획을 형성(징검다리)–전이로 구분 |
| 기존 정책과의 관계 | 배움중심수업(학생 중심 전환), 주제중심 프로젝트(삶과 연결), 교육과정-수업-평가-기록 일체화(성취기준 기반 일관성)를 **단원·전이까지 넓히는 보완** | 수석교사 역할수행계획서의 정책 연속성 서술에 활용 |
| 간소화는 전문성 | 핵심을 안 뒤에야 덜어낼 수 있다. 양식 간소화는 설계 원리를 이해한 뒤의 전문적 판단 | 간략 지도안 작성 시 근거 |
| 교사는 설계자 | 성취기준·핵심 아이디어·내용 요소는 교사가 읽고 해석할 때 배움이 된다. 통합 설계의 중심은 교사의 교육과정 전문성 | 수석교사 '교육과정 전문성' 진술 근거 |

### 사례 1. 『동물농장』을 읽고 진정한 공동체 탐구하기 — 원덕초 임소연 (14~19쪽)
- **설계**: 핵심 질문 "진정한 공동체는 어떻게 만들어질까?" 12차시. 미리 읽은 고전(동물농장)의 문제 상황 → 학생이 탐구질문 만들기 → 토론(자유와 공동체) → 민주화 운동 → 민주적 공동체 → 산업화 → 산업화 이후 사회 문제.
- **공개 차시(1차시)**: 대사로 인물 맞히기 → 스노볼 추방·7계명 변경 장면에서 문제 관찰 → 질문 만들기·분류·묶기 → 탐구질문 확정, **생각수직선**에 입장 표시(토론 후 변화 다시 표시).
- **평가**: 탐구할 가치가 있는 질문 만들기 / 생각 표현·의견 존중, 서술형·발표.
- **컨설팅(양평초 수석교사 장지현)**: 교육과정 분석 → 단원 설계 → 차시 계획 → 본차시 구체화 → 자료 점검 순서. 이미 읽은 작품을 사회 개념과 잇는 동기유발 발문, 학생이 탐구질문을 만드는 도입 차시를 함께 고민.

### 사례 2. 작은 선택을 쌓아 만들어 가는 나다움 — 용인이동초 송언주 (22~29쪽, 3학년)
- **설계**: 도덕(자아 탐구·성실) + 사회(일상 속 과거, 역사적 존재로서의 나) 통합 22차시. 핵심 질문 "'나다움'은 어떻게 만들어지며, 어떤 '나'로 자라고 싶을까?" GRASPS 수행과제(나다움 박물관 발표).
- **배움 덩어리**: ① 나 만나기(그림책 『작은 조각 페체티노』, 나의 조각 카드) ② 나의 연표(과거의 나) ③ 되고 싶은 나와 성실한 선택.
- **평가**: 되고 싶은 나를 구체적으로 표현 / 꾸준히 실천할 계획 수립.
- **컨설팅(어정초 수석교사 김미영)**: 조각 카드와 연표가 같은 질문을 반복하는 것처럼 보이지 않도록 역할을 구분 — 조각 카드는 '지금의 나에 대한 선언', 연표는 '경험이 지금의 나를 만든 인과 설명'. 의도가 설계안에 드러나고 수업과 평가가 일관되는지 점검.

### 사례 3. 환경을 변화시키는 ART.IST — 옥길산들초 신종근 (32~39쪽, 6학년)
- **설계**: 미술·창체·국어 통합 12차시, 개념기반 탐구. 핵심어 공공미술·행동·자발성·변화. 핵심 질문 "학교 공간에 공공미술이 더해진다면 우리는 어떤 점이 달라질까?" 학교 문제 찾기 → 공공미술 탐색 → 설계 → 피드백 → 제작.
- **공개 차시**: 모둠 설계 아이디어 **갤러리 워크** → 미리 정한 기준으로 좋은 점·보완할 점 피드백 → 피드백 반영해 보완.
- **평가**: 피드백하기 / 피드백 수용해 아이디어 발전, 관찰·포트폴리오.
- **컨설팅(부천양지초 수석교사 신수나)**: 핵심 문장이 교사 의도대로 진술되지 않는 어려움 → **의도가 담긴 핵심어를 넣어 핵심 문장 재진술**, 개념적 탐구질문을 '관계 중심'으로 정교화. "무엇을, 왜 평가하는가" 함께 성찰.

### 사례 4. 마을 소식지 만들기 — 가평마장초 조현희 (42~49쪽, 2학년)
- **설계**: 통합교과 '마을' 24차시. 핵심 질문 "우리 마을의 어떤 점이 소중하며, 그것을 어떻게 표현하고 함께 나눌 수 있을까?" 읍·면 소규모 학급의 마을 탐험.
- **공개 차시**: 군 소식지 실물 보기 → 패들렛 조사 자료 공유 → 알리고 싶은 정보 고르기(읽는 사람 고려) → 소식지 표현.
- **평가**: 정보 선택과 까닭 / 글·사진·그림으로 표현 / 소통하며 조정, 관찰·실기·발표.
- **컨설팅(가평초 수석교사 이영애)**: 난독 학생·특수학급 학생이 글쓰기 중심 활동에서 소외되지 않도록 **사전 조사 기간 확보, 사진·그림·짧은 문장 등 표현 방법을 열어 둠**.

### 사례 5. 우리 주변 경제활동으로 생산과 소비 알아보기 — 덕정초 서선경 (52~57쪽, 4학년)
- **설계**: 핵심 질문 "생산과 소비 활동은 지역과 사람들을 어떻게 이어 줄까?" 9차시, 생산·소비 → 교류 → 상호의존.
- **공개 차시**: 앞 소단원의 '학교 주변 가게와 물건' 자료 재활용 → 경제활동을 두 가지로 **분류하고 기준 설명** → 공통점에서 생산·소비 뜻 도출. 탐구질문의 핵심 낱말을 **비워 두고 제시**("○○과 ○○는 무엇이며…")해 개념을 학생이 채우게 함.
- **평가**: 생산·소비 의미와 생활 관련성 설명, 4단계 성취수준(매우잘함~노력요함), 발표.
- **컨설팅(덕정초 수석교사 김순례)**: 활동의 양보다 **활동이 개념 이해로 이어지는 과정** — 분류 기준을 설명하고 그것이 개념 뜻과 어떻게 연결되는지 말하게 함, 차시 간 연결성 점검.

### 사례 6. AI 마음 거울 프로젝트 — 성남정자초 김승희 (60~67쪽, 2학년)
- **설계**: 사회정서교육 + AI 12차시. 『아홉 살 마음 사전』으로 감정 단어 → 엔트리 텍스트 분류 모델 학습 → AI 오분류 검증 → '따뜻한 입'(공감 대답) 설계·코딩. 핵심 질문 "인공지능이 우리 마음을 더 잘 이어주려면 우리는 AI에게 어떤 말을 가르쳐야 할까?"
- **평가**: 공감적 언어 표현 / 디지털 시민성(AI는 사람을 돕는 도구), 관찰·실기.
- **컨설팅(청솔초 수석교사 김인숙)**: 핵심어·핵심 질문·탐구 질문을 **2학년 눈높이로 정교화**, AI의 단조로운 분류 답변을 공감 언어로 확장해 기술과 사회정서가 끊기지 않게 구조 조정.

## 4. 수석교사 관점 정리 (컨설팅 6편 공통점)

1. 컨설팅 순서: 수업자 의도·학생 특성 대화 → 교육과정 분석 → 단원 설계 → 차시 계획 → 본차시 구체화 → 자료 점검
2. 가장 많이 다룬 지점: **핵심 문장·핵심 질문·탐구 질문의 정교화**(학년 눈높이, 의도가 담긴 핵심어, 관계 중심 개념 질문)
3. **수업–평가 일관성**: 교사의 기대가 수업으로 구현되고 평가로 확인되는가
4. **포용**: 수준 차이·특수교육 대상 학생을 위해 표현 방식을 열어 둠
5. 활동의 양보다 **활동이 개념으로 정리되는 과정**
