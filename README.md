# 초등 교과별 성취수준 정리 (2022 개정 교육과정)

수석교사 준비용 자료. 9개 교과의 학년군·영역별 성취수준(A·B·C)을 과목별 파일로 정리했습니다.

> 학년군·영역 구성은 2022 개정 교육과정(교육부 고시 제2022-33호) 기준입니다. A·B·C 기술은 한국교육과정평가원 '성취수준의 일반적 특성'(초등 3단계)을 영역에 적용해 정리한 것으로, 평가원 「2022 개정 교육과정에 따른 성취기준별 성취수준(초등학교)」 원문과 문구가 다를 수 있습니다. 평가계획·통지에 쓸 때는 원문과 대조하세요.

## 학년별 파일 (2026학년도 연간 지도 계획 기준)

[1학년](학년별/1학년.md) · [2학년](학년별/2학년.md) · [3학년](학년별/3학년.md) · [4학년](학년별/4학년.md) · [5학년](학년별/5학년.md) · [6학년](학년별/6학년.md)

각 학년 파일에는 그 학년에서 다루는 성취기준(코드·원문)이 과목별로 학기·단원과 함께 정리되어 있고, 영역 성취수준(A·B·C)이 붙어 있습니다. 같은 내용을 엑셀로 정리한 [초등_성취기준_학년별.xlsx](초등_성취기준_학년별.xlsx)도 있습니다(학년별 시트, 미배치 시트, 학년군 원본 대비 시트).

## 성취수준의 일반적 특성 (초등 3단계)

| 수준 | 특성 |
|---|---|
| A | 개념·원리를 정확히 이해하고, 새로운 상황에 전이·적용하며, 관련 기능을 능숙하게 수행한다. |
| B | 개념·원리를 대체로 이해하고, 익숙한 상황에 적용하며, 관련 기능을 무리 없이 수행한다. |
| C | 개념·원리를 부분적으로 이해하고, 교사의 안내나 도움을 받아 기본적인 기능을 수행한다. |

## 학년별 적용

초등 교육과정은 학년군(1~2, 3~4, 5~6학년) 단위로 성취수준이 제시됩니다. 같은 학년군의 두 학년은 동일한 성취수준을 공유하고, 학교 교육과정에서 학년별로 성취기준을 배분해 적용합니다.
